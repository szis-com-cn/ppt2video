# 数字人视频生成API选型调研报告

> 负责人：彭逸远

## 1. 目标
调研数字人视频生成API的功能、性能、价格等方面，选择最适合的API进行数字人视频生成。

## 2. 选型标准
- **功能性**：API需支持多种输入格式（如文本、音频、视频）和输出格式（如视频、图像）。
- **性能**：生成视频的速度和质量，包括分辨率、帧率等。
- **价格**：根据预算选择合适的收费方案，包括免费额度和付费套餐。

## 3. 主要候选平台
- **Hedra**
- **D-ID**
- **本地部署SadTalker**
- **HeyGen**
